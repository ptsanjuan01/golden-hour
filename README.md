# **GOLDEN HOUR: a macOS 27-inspired Tumblr theme**


Introducing **[Golden Hour](https://navi-0304.tumblr.com/post/832250829562101760/golden-hour-a-macos-27-inspired-tumblr-theme)**, a fully interactive, macOS 27-inspired desktop theme for Tumblr!

**[Static preview](https://ptsanjuan01.github.io/golden-hour/index.html)**| **[Free version](https://payhip.com/b/lT9ug)** | **[Full version](https://payhip.com/b/kUdiO)**

## **Features**


### _Desktop & Interface_
* Initial boot screen that mimics a Mac powering up
* Finder-style main blog window with sidebar navigation
* Interactive Dock, menu bar, Control Center, and Spotlight Search
* Draggable windows, desktop icons, and widgets
* Light, dark, and automatic appearance modes
* Customizable accent colors, folder colors, and wallpapers
* Responsive layout for mobile and smaller screens

### _Widgets_
* Calendar widget
* Customizable blog profile widget
* Updates widget
* Music player with up to 6 songs and audio previews
  
### _Applications & Custom Windows_
1. **Finder:** Your main blog, with posts displayed as files, sidebar shortcuts, tags, and search
2. **Notes:** Customizable About page with up to 5 additional notes, images, lists, and checklists
3. **Messages:** Create up to 3 custom conversations with message bubbles, timestamps, and read receipts
4. **Photos:** Display up to 24 photos across two albums, with captions and video support
5. **Mail:** Custom Ask window
6. **Links:** A dedicated window for your custom links
